## What Module 1 IS

| Chapter | Name | Student learns | Ends when |
|---------|------|----------------|-----------|
| 1 | Linear Search | Array, index 0, check one-by-one, O(n), C `for` loop | Lost file found + quiz/code done |
| 2 | Binary Search | Sorted data, left/right/mid, O(log n), C while loop | Fast find done + quiz/code done |
| 3 | Bubble Sort | Adjacent swap, passes, O(n²), C nested loops + `temp` | Archive ordered again |

**Story start:** Scramble Fault hits Quantum Archive; CODA greets Trainee in Hub.  
**Story end (Module 1 stop line):** Bubble Sort restores order → Module 1 clearance (Archive Operator Rank 1) → golden rule spoken → **stop**.

**Golden rule:**  
Search power depends on data order. Sorting creates that order.

## How play works now

1. Hub opens → CODA opening (first run)  
2. Only Chapter 1 unlocked at start  
3. Finish Chapter 1 → unlocks Chapter 2 → unlocks Chapter 3  
4. Starting Chapter 1 runs **Story Mode** (auto-continues 1→2→3)  
5. Starting Chapter 2 or 3 from hub (when unlocked) is **single chapter**, then back to hub  
6. Progress / badges save to `user://module1_progress.cfg`
